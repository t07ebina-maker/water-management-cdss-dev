# 特定行為（水分管理）判断支援ツール

水分管理に関する情報整理、脱水タイプの分類、水分欠乏量・維持輸液量の計算を支援する日本語のブラウザーアプリです。HTML・CSS・JavaScript で構成しており、ビルドや外部ライブラリのインストールは不要です。

> 本ツールは診断を行いません。思考過程の可視化と計算支援を目的としています。計算結果は参考値であり、最終決定・輸液処方は必ず医師の指示に基づいてください。

## 主な機能

- 基本情報、体重・測定日、バイタルサイン、身体所見、血液検査、侵襲・ストレス状態の入力
- 入力値の検証と Critical / Warning / Info アラートの表示
- eGFR、血清浸透圧、体重変化などの計算
- 脱水タイプの分類と、体重法・Na法・Hct法・TP法による欠乏量推定の比較
- 維持輸液量、輸液計画、Na補正速度、モニタリング項目の表示
- サンプル症例の読み込みと、結果の印刷・PDF保存（ブラウザーの印刷機能）

Critical アラートや入力エラーがある場合は、第2段階への進行を停止します。

## 起動方法

JavaScript が有効なブラウザーを使用してください。ローカル開発では Python 3 の静的サーバーを利用できます。

```bash
cd water-management-cdss-dev
python3 -m http.server 8000 --bind 127.0.0.1
```

同じマシンのブラウザーで `http://127.0.0.1:8000` を開きます。終了するにはサーバーの端末で `Ctrl+C` を押します。

## 基本的な使い方

1. 必須項目を入力するか、サンプル症例一覧から症例を選択します。
2. 入力エラーとアラートを確認します。
3. 「第2段階へ進む」を選び、分類・計算結果とその根拠を確認します。
4. 必要に応じて「印刷 / PDF 保存」を使用します。

## 開発・動作確認

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力画面と結果表示領域 |
| `style.css` | レイアウト・表示スタイル |
| `main.js` | 入力検証、計算、アラート、サンプル症例、画面操作 |

現時点ではパッケージ管理、ビルド設定、自動テストスイートはありません。

変更後は、ブラウザーで次の操作を確認してください。

1. 初期表示で「第2段階へ進む」が無効になっている。
2. サンプル「②高張性脱水・軽度（73歳女性）」を選ぶと入力が反映され、次段階へ進める。
3. 第2段階に計算結果と「Na補正速度の安全計算」が表示される。
4. サンプル「③高張性脱水・重症（85歳男性）」を選ぶと Critical アラートが表示され、進行が停止する。
5. ブラウザーのコンソールに JavaScript エラーがない。

上記は変更後の手動確認手順です。ソフトウェアの動作確認であり、計算式・閾値の臨床的妥当性を検証するものではありません。

## 計算上の前提

計算式や閾値の詳細は `main.js` と結果画面の注記を参照してください。特に、BNP の閾値は本ツールの慎重投与判断に用いる参考値です。Na異常の急性・慢性判定には体重変化日数を代用しており、病歴と再検査による確認が必要です。

## データの扱い

現在の実装では入力と計算をブラウザー内で処理します。外部APIへの送信、データベースへの保存、ブラウザーストレージへの永続保存は実装していません。印刷・PDF保存した情報は、保存先の管理方針に従って取り扱ってください。
